# Changelog

Tüm önemli değişiklikler bu dosyada listelenecektir.  
Bu proje [SemVer](https://semver.org/lang/tr/) sürümleme sistemini takip etmektedir.  

---

## [1.1.0] - 2025-01-19
### Eklendi
- `/kanun-listele` komutu ile yürürlükteki ve bekleyen kanunların embed formatında listelenmesi.
- Kanunların geçmesi için %50 üzeri oy şartı.
- Modern glassmorphism tasarımı ile web admin paneli.
- Soluk alan (breathing) animasyonlu butonlar ve görsel efektler.
- Responsive tasarım ve mobil uyumluluk.
- Chart.js entegrasyonu ile görsel istatistikler.
- Session-tabanlı admin giriş sistemi.
- Tüm Discord komutlarında ve web panelinde v1.1.0 sürüm bilgisi.
- Profesyonel embed footer'ları tüm komutlarda.

### Değiştirildi
- Kanun onay sistemi güncellendi, artık otomatik geçiş yok.
- Web panel arayüzü tamamen yeniden tasarlandı.
- Admin giriş sayfası modern bir görünüm kazandı.
- Database integration tamamen yenilendi.

### İyileştirmeler
- Kod yapısı daha modülar hale getirildi.
- Küçük performans optimizasyonları yapıldı.
- UI/UX deneyimi büyük ölçüde geliştirildi.
- Profesyonel branding ve sürüm tutarlılığı sağlandı.
